# WeChatBot

**版本 0.6.1 · Windows 本机微信群聊机器人工作台 · AGPL-3.0-or-later**

WeChatBot 通过现有微信桌面窗口收发群消息，在本机网页管理模型、人设、群成员、知识、记忆、联网工具和运行记录。项目仍在完善中，桌面自动化受微信版本、窗口状态和 UIA 可访问性影响。它不是微信官方服务，也不是可直接部署到无桌面云服务器的机器人。

`main` 只保留正式界面；`linuo` 是独立主题分支。主题不同不改变后端数据协议。发布版本以 `main` 的 `v0.6.1` 标签为准。

## 能做什么

- 监听已明确绑定并完成验收的群，响应 @、显式命令及限频主动参与；全局暂停可阻止自动回复。
- 通过 Pi Agent 接入 OpenAI 兼容、OpenAI Responses、Anthropic、Google 协议；聊天、判断、记忆与视觉可分工配置。厂商服务和模型能力需实际测试。
- 编辑全局与群人设、风格、示例及特殊人格；对话预览使用草稿与真实模型，不向微信发送，也不写正式记忆，但会产生模型费用。
- 导入 TXT、Markdown、文字型 PDF 与网页；关键词检索与可选向量检索；管理候选、冲突、固定和共享记忆。
- 按群管理成员和个人记忆；身份不确定时不强行认人，不合并同名成员，不凭界面昵称授予特殊权限。
- 使用 DeepSeek Search/Fetch 或 SearXNG 搜索与读取公网网页；有效来源自动收录知识库，同一网页去重更新。搜索失败不应阻断普通聊天。
- 管理图片、表情素材、菜库及群功能；可选本地 OpenCLIP 图片相似度检测、触发图库、追猎队列与成员白名单。
- 查看任务、发送、错误、模型用量和费用。未知 token 或价格保持未知，不伪造统计。

## 安装与部署

### 准备

使用 Windows 10/11 交互式桌面、Node.js >=22.19、Python 3.12、Git 和运行中的 Docker Desktop（Linux 容器）。微信 4.x 必须由你手动登录并保持主窗口可访问；桥接依赖锁定 `wx4py==0.2.1`。客户端更新后需重新验收，不能推定所有 4.x 版本均兼容。

```powershell
git clone https://github.com/JeropsWang/WeChatBot.git
cd WeChatBot
Copy-Item .env.example .env
./scripts/setup.ps1
```

安装会分别安装根目录和网页 npm 依赖，创建 `.venv`、安装锁定的 Python 桥接依赖、启动基础服务并构建网页。首次下载 npm、Python 包与容器镜像需要网络。`-NoStart` 只准备环境；已安装依赖时可用 `-SkipInstall`。不要用管理员权限解决来源不明的安装错误，先检查输出。

图像匹配为可选组件，首次准备时运行：

```powershell
./scripts/setup.ps1 -WithImageMatching
```

该选项准备独立 `.venv-image-match` 及公共模型权重，可能需要较多下载流量与磁盘空间。普通聊天不需要图像环境。没有自有参考图时图库为空，追猎关闭；安装后从网页上传有权使用的静态图片并保存选择。模型运行使用本地缓存，不把输入图片上传给 OpenCLIP 服务。调用云视觉模型是另一项独立配置，图片会发送给该模型服务。

### 启动与端口

```powershell
./scripts/start.ps1
```

浏览器打开 [本机工作台](http://127.0.0.1:4310)，创建至少 12 位管理员密码，没有默认管理员密码。应用保持在当前终端运行；Ctrl+C 停止应用。停止前先全局暂停，并在网页停止由工作台启动的桥接，避免中断发送。

| 服务 | 本机地址 | 作用 |
| --- | --- | --- |
| 工作台/API | 127.0.0.1:4310 | 正式构建与管理员接口 |
| 开发网页 | 127.0.0.1:4311 | Vite 开发服务 |
| PostgreSQL | 127.0.0.1:54329 | 主数据与向量 |
| Redis | 127.0.0.1:63799 | 队列与缓存 |
| SearXNG | 127.0.0.1:43889 | 可选搜索后端 |

应用仅允许本机绑定及访问。Compose 中的数据库账号是公开的本机开发默认值，不是生产机密；不要将端口转发到公网。不要把 Windows DPAPI 密钥保护理解为远程访问防护。网站静态预览和 Sites 打包均不能替代 Windows 后端与微信桌面。

`.env.example` 列出连接地址、数据目录、队列前缀、桥接令牌和实验测试群配置；实际 `.env` 不提交。`BRIDGE_TOKEN` 可留空由服务创建，手动运行桥接时须与服务保持一致。`WECHATBOT_TEST_GROUP` 默认留空，诊断实验默认关闭；只有专门测试时才显式设置测试群，仍须遵守暂停和验收门禁。

## 首次使用

1. 保持全局暂停。在“模型”添加地址、模型标识和密钥，执行连通测试，选择聊天模型；判断、记忆、视觉按需单独配置。兼容服务须使用厂商对应 `/v1` 地址；本地 Ollama、LM Studio、vLLM 也需提供兼容协议。不要将聊天模型名称当作视觉能力保证。
2. 在“微信与群聊”查看诊断并启动桥接。输入群的准确名称、绑定并启用监听；同名群或不完整搜索结果会拒绝猜测。使用发送测试标记，再在目标群 @机器人，最后完成网页验收。验收会真实发消息，应在自己控制的测试群操作。
3. 在“人设与风格”设置全局规则、示例及群覆盖。先保存或明确保留草稿再切换配置；预览调用真实模型。不要在提示词里放密钥或不必要的个人资料。
4. 在“知识与记忆”导入资料。文字 PDF 可提取，扫描 PDF 不提供 OCR 保证。向量服务未配置时仍可关键词检索；切换嵌入模型会重建索引。
5. 在“联网工具”选择 DeepSeek 并填写独立密钥，或填写支持 JSON 的 SearXNG 地址，保存后分别测试搜索和读取。网页只允许公网 HTTP/HTTPS；结果与记忆均作为资料，不具有系统指令权限。
6. 按需配置成员、素材、菜库、图片触发与白名单。图片相似度是未经概率校准的余弦分数，不能用于身份认定；没有环境、权重或有效参考图时不启用自动触发。
7. 确认群已启用并通过收发验收，再解除全局暂停。主动参与默认冷却 120 秒、滚动一小时 10 次、每 20 秒最多判断一次；@与显式命令独立处理。

| 群命令 | 用法 |
| --- | --- |
| `/帮助`、`/help` | 查看命令 |
| `/状态`、`/status` | 当前运行状态 |
| `/搜索 关键词`、`/search 关键词` | 使用已保存的联网服务 |
| `/记住 一件事`、`/remember 一件事` | 申请记忆写入；身份和证据不足时拒绝写入 |
| `/停止`、`/stop` | 取消当前群回复链路 |

修改模型、人设与删除记忆通过管理员网页操作。追猎白名单绑定本群成员 ID，改昵称仍有效；保存后重新检查待发送结果，不能把同名成员一并豁免。

## 数据与发送语义

共享记忆可跨群检索，短期聊天按群隔离；成员档案、模式、权限和个人检索按群及成员隔离。个人记忆只基于可靠当前消息证据生成。固定、候选、冲突记忆不会被自动整理直接覆盖；失败保留原数据。删除成员档案会删除关联个人记忆、历史及权限，包括固定记忆，但不清空群聊天，也不删除离线备份。

服务每天北京时间 04:00 清理 30 天前聊天正文，启动补跑；长期记忆和身份不随正文到期清除。过期不确定发送保留无正文账本，不能重试已经清理的载荷。

桥接收件箱落盘后才上报，服务端 ACK 后才移除；消息事件按 ID 去重，不按文字去重。发送按 commandId 记账；不确定结果标为“待核查”，核对真实群聊后处理，禁止为了恢复状态而盲目重发。本地气泡确认不等于对端已读。

## 备份、恢复与升级

```powershell
node scripts/backup.mjs
```

工具只支持本机 Compose 的 54329 PostgreSQL，备份到新目录，包含数据库 dump、附件、桥接 SQLite 在线快照、DPAPI 密文密钥库与令牌。先暂停并停止桥接，避免跨时点修改。备份仍含敏感资料，不上传 GitHub。当前备份脚本未覆盖全部图像图库、模型缓存及其他数据子目录；完整迁移还需在应用和桥接停止后另外保存整个 `DATA_DIR` 与 `.env`，并核对文件清单。

恢复时保持应用和桥接停止，用 `pg_restore` 将 dump 导入新的空数据库，修改 `DATABASE_URL` 指向该库，再恢复附件、SQLite 及其他所需数据到 `DATA_DIR`。不要覆盖含需保留数据的数据库。DPAPI 密文只有原 Windows 用户可解密，换电脑或用户后应重新填写服务密钥。桥接重启后中断发送可能进入待核查。

升级前备份，查看 [变更记录](CHANGELOG.md)，检出明确发布标签，重新安装两套 npm 锁文件和桥接锁文件、构建后启动。迁移由启动流程执行；回退代码不代表数据库可自动降级，数据库回退应使用独立备份恢复。

## 常见问题与实际限制

- 网页提示依赖不可用：检查 Docker Desktop、容器健康和 `.env` 端口，确认未连到测试库。
- 桥接没有聊天控件：检查微信已登录、窗口可见、桌面未锁定。临时无障碍兼容必须每次明确勾选，只对核验版本生效，由独立守护进程恢复；不要绕过哈希校验。
- 群不回复：依次检查全局暂停、群启用、验收、模型选择、密钥、运行记录和待核查发送。不要反复点击重试制造重复发送。
- 图库不可用：先准备可选环境与公共权重，再上传自有参考图；空图库不是安装失败。
- 模型费用未知：补充价格，缓存读写成本以厂商实际返回为准，不以命中率截图推定省费。
- UIA 只能看到可见消息。长时间离线、滚动丢失、同文不可观测变化及窗口结构改变可能造成缺口，不能当作完整微信历史导出器。
- 多群并发、微信升级、完整客户端重启恢复、真实云/本地模型和付费接口均需在自己的环境逐项验收。自动化测试不是这些能力的实机认证。
