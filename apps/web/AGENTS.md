# WeChatBot 正式版前端维护约定

本分支只包含正式界面。暖石色、墨蓝、陶土色，中文宋体/衬线标题与无衬线正文；不添加角色立绘或外观切换。保留七项主导航及现有业务流程。其他主题单独维护。

- 在 src 实现界面，复用 API 与公共协议，不复制业务状态。
- 只显示真实配置与 API 返回；未知身份、能力、用量、价格保持未知。
- 保护未保存草稿，失败保留输入。成员、模式和权限按群隔离。
- 服务端分页 20/50/100 行；批量删除用冻结令牌，固定记忆需明确确认。
- 兼容模式每次启动明确同意；发送待核查不能显示成功或自动重发。
- 保留 Sites hosting 配置、worker、构建准备脚本和打包测试。
- 验证 typecheck、build、test:sites；浏览器检查 1440/768/390。使用隔离测试数据库、关闭工作进程，不触发真实微信收发。
