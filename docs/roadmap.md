# 后续改进计划

以下为优先级排序，不是已完成能力或时间承诺；任务可通过 Issue 拆分并附验收条件。

1. **部署复现**：持续进行空机/干净克隆验证；减少图像环境下载体积，明确可选组件状态与恢复指引；扩展备份清单覆盖所有数据子目录并验证恢复一致性。
2. **安全与测试**：完善依赖和凭据扫描、可重复的合成夹具、迁移升级覆盖与最小权限运行；私密漏洞报告渠道常态化。
3. **桥接稳定性**：建立客户端版本兼容矩阵，测试锁屏、窗口变化、重连、多群负载与不确定发送；守护恢复失败应可观察且禁止继续发送。
4. **模块拆分**：渐进拆分大型路由和流水线文件，保持契约及事务边界；分离生产识别和诊断实验入口，避免引入第二套业务逻辑。
5. **可观测性与体验**：统一任务/发送追踪、局部依赖错误、成本未知状态、队列延迟与取消原因；完善键盘和移动布局验收。

修复递增补丁版本，兼容新增功能递增次版本；破坏协议或数据兼容时必须显式说明迁移与回退路径。发布标签只指向验证过的 main 提交，linuo 保持后端同步并单独验证主题差异。
